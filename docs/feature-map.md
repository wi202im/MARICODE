# Maricode 기능 지도

작업 화면(`/workspace`)의 기능을 **사용자가 하려는 일** 기준으로 모았다. 테스트 안내서이자 중복·파편화 점검표다. 2026-11-04 코드 기준이며, 상태는 [handoff.md](handoff.md)를 따른다.
표기: ⋯ = 가운데 위 ‘세션 동작’ 메뉴, ⌘K = 명령 팔레트, ⚠ = 중복·파편화·동선 문제 후보.

## 8. 점검 결과 요약 (사용성 개선 후보)

2026-11-04 사용자 결정: 1(계정 한 곳) · 3(diff 가운데 탭) · 4(세션 동작 메뉴 정리) 반영, 6(모델·추론·액세스 각각 적용)은 유지. 2(이어가기 이름)는 ‘다른 AI로 인계’로 바꿈. 5는 패널을 여는 동작에 스크롤·강조를 넣음.
1. **계정·로그인이 다섯 곳에 흩어져 있음.** 한 곳(예: 컴퓨터 설정 또는 계정 화면)으로 모으고 나머지는 그곳으로 보내는 링크만 둘지 정해야 한다.
2. **‘이어가기’가 세 가지 뜻.** 터미널에서 이 세션 이어가기 / 다른 AI로 인계 / 종료된 세션 자동 재개. 이름을 일로 구분해야 한다.
3. **diff가 두 곳에 두 모양.** 턴 변경은 가운데 탭, Git 변경은 오른쪽 패널 안. 한 방식(가운데 탭)으로 맞출지 정해야 한다.
4. **⋯ ‘세션 동작’에 성격이 다른 것이 섞임.** 상태 확인·계정·실시간 연결 끊기·기기 연결 코드·실행 종료가 한 메뉴에 있다.
5. **결과가 다른 곳에 나타나는 동작.** 변경 카드의 ‘Git 전체 변경’, 계정 메뉴는 누르면 오른쪽 패널이 열린다. 어디가 바뀌었는지 눈에 띄게 알려야 한다.
6. **모델·추론·액세스를 각각 적용.** 한 번에 고르고 한 번 적용하는 흐름이 자연스럽다.

이 문서는 기능을 더하거나 옮길 때 같이 고친다.
