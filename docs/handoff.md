# MARICODE 인계

상태는 이 파일, 요구사항은 [goals.md](goals.md), 이전 과정은 Git 로그를 따른다.

## 후속 수정 — Claude 목록·업데이트 종료 흐름 (DMG 미배포)

- 사용자 요청: CLI와 같은 제목으로 기존 Claude 세션을 찾고 가능한 한 제외하지 않는다. 업데이트 다운로드 뒤 기존 앱을 종료하고 설치로 이어간다. ‘개인정보 권한’ 문제는 파일 접근이 아니라 공증 없는 앱의 Gatekeeper 실행 차단임을 사용자가 확인했다.
- **된다 — 구현/자동 검사:** 목록을 전체 가져오기 검증과 분리했다. 본체 앞/뒤 각64KiB와 선택적 sessions-index 메타데이터로 제목을 읽는다. 사용자 지정 제목 → AI 제목 → 마지막 입력/요약/첫 유효 입력 순으로 표시하고 내부 안내문은 제목에서 제외한다. 최신순50개씩 추가 로딩하며 기존500개/전체128MiB 검색 예산에 따른 누락을 없앴다. UUID 형식의 세션 파일이 손상·심볼릭 링크·폴더 불일치·크기 초과인 경우도 항목과 사유를 남긴다. 모든 JSON 파일이나 다른 작업 폴더를 합치는 방식은 아니다.
- 선택 후 가져오기는 전체 검증을 유지한다. 파일당256MiB·본체/하위 에이전트 합계512MiB로 한도를 늘렸으며 초과도 목록에서 확인한다. 목록에 보인다고 가져오기 성공을 보장하지 않는다. 선택 뒤 원본/하위 에이전트 변경은 차단하고 기존 ID 덮어쓰기·미확인 등록 재전송 보호는 유지한다. 가져온 세션 이름에 별도 접미사를 붙이지 않는다.
- **된다 — 구현/자동 검사:** 검증된 DMG의 ‘앱 종료 후 설치’는 기존 정상 종료 경로로 들어간다. 실행 세션 종료 확인·취소·오류·미확인 상태를 존중하며 정상 종료 뒤 해시를 재검사하고 DMG를 연다. 취소·실패하면 설치 의도를 폐기하여 이후 일반 종료에서 설치가 실행되지 않는다. 취소 콜백은 로컬 메인 프레임/원래 작업 WebView/해당 요청 nonce만 허용한다. 파일 교체는 설치 디스크에서 사용자가 직접 한다. 앱/설치 안내에서 업데이트 후 Gatekeeper 재확인 가능성과 보안 설정 바로가기를 설명한다. 격리 속성이나 macOS 보안을 해제하지 않는다.
- **된다 — 검증:** 제품 자동 검사269개와 macOS14 대상 전체 Swift 앱 컴파일 통과. 502개 목록·큰/손상 기록 표시·65MiB 정상 기록 가져오기·원본 변경 차단·제목 보존·페이지 추가/선택 유지·설치 중복/취소/비정상 종료/변경된 DMG 차단을 확인했다. 격리된 실제 Chrome에서 제품 검색 패널과 제품 목록/복사 코드를 사용해 합성 기록52개 추가 로딩, 사유 표시, 정상 기록 선택/복사·합성 Hub 등록을 확인했다. 실제 Claude 응답 시험은 아니다.
- **확인 안 함:** 회사 실제 기록의 CLI 목록/제목 일치와 맥락 응답, 네이티브 앱 종료→Finder DMG 열기의 실제 왕복, 새 배포본 설치/Gatekeeper 승인. 사용자 앱·서버·계정은 변경하거나 종료하지 않았다.
- **다음:** 사용자가 요청하면 이 수정으로 새 버전 DMG를 빌드·검증·공개한다. 현재 공개 latest는1.0.5이며 이번 수정이 포함되지 않았다.

### 수정 전 확인한 원인

- 사용자 화면에서 CLI와 MARICODE의 작업 폴더 표시는 같지만 목록/제목이 다르고, MARICODE는8개 발견·6개 제외로 표시된다. 실제 회사 기록은 읽거나 수집하지 않았다. CLI의 실제 프로필 위치가 자동 탐색 후보와 같은지는 화면만으로 확정할 수 없다.
- **코드 확인:** 목록 검색이 가져오기용 snapshot 전체 검증을 재사용한다. 본체/하위 에이전트 합산64MiB 제한과 전체 검색128MiB 제한, 모든 user/assistant 행의 ID/cwd/UUID 검사 중 하나라도 실패하면 세션 전체를 숨긴다. 파일을 최신순으로 먼저 정렬하지 않고 읽기 예산을 소모한 뒤 결과만 최신순으로 정렬하므로 오래된/제외된 기록이 예산을 소비해 최근 기록이 빠질 수 있다. 화면의 큰 기록이 구체적으로 어느 제한에 걸렸는지는 미확인이다.
- **코드 확인:** 제목은 custom-title 또는 첫 문자열 user 입력만 사용한다. local-command-caveat 등 내부 안내/로컬 명령을 제외하지 않아 실제 대화 제목 대신 내부 문구가 표시된다. CLI와 같은 세션도 다른 이름처럼 보일 수 있다.

## Claude 기록 위치 선택·자동 탐색 (1.0.5 포함)

- 사용자 요청: 별도 Claude 기록 폴더를 직접 찾아 선택하고, 가능하면 CLI에 설정한 저장 위치를 자동으로 불러온다. 이번 변경은 기존 기록 검색 범위이며 AI 계정·설정·MCP를 자동 가져오는 기능이 아니다.
- **된다 — 구현/자동 검사:** 로컬 Mac 앱에 ‘기록 폴더 선택…’을 추가했다. NSOpenPanel이 숨김 폴더를 표시하며 projects가 들어 있는 프로필 루트를 고른다. 결과는 원래 로컬 작업 화면의 요청 ID에만 전달하고 취소/작업공간 변경/처리 중에는 검색 대상을 바꾸지 않는다. 선택 후 현재 작업 폴더의 기록을 자동 재검색한다. 직접 입력은 ~/와 절대 경로를 지원한다.
- **된다 — 자동 탐색:** 명시 경로 → 앱이 받은 CLI 환경변수 → 사용자 zsh/bash 설정의 단일 정적 경로 후보 → 기본 ~/.claude 순으로 조회한다. 출처와 실제 경로를 표시한다. 셸 파일을 실행하지 않으며 조건문·별칭·함수·명령 치환·복수 후보는 직접 선택으로 넘긴다. 셸 정적 후보는 실제 실행된 CLI 환경과 동일하다고 보장하지 않는다. AI 실행은 기존 전용 프로필을 유지하고 과거 미확인 가져오기의 빈 경로는 기존 ~/.claude 의미를 유지한다.
- **된다 — 검증:** 자동 검사263개, macOS14 대상 Swift 앱 컴파일 통과. 격리된 실제 브라우저+제품 검색 패널+합성 기록에서 셸 경로 자동 탐색/한글 목록, 폴더 선택 결과 주입 후 재검색, ~/ 입력 재검색을 확인했다. 잘못된 입력은 기록 없음으로 안내했다. 폴더 선택 콜백은 합성이며 NSOpenPanel 직접 클릭 시험으로 표기하지 않는다.
- **확인 안 함:** macOS 폴더 선택창 실제 클릭, 회사 실제 설정/기록 발견·맥락 답변, 갱신 DMG 설치. 기존 사용자 앱/서버는 변경하거나 종료하지 않았다. 이번 시험 서버·탭은 정리했다.
- **다음:** 사용자 환경의1.0.5 설치·실사용 피드백을 확인한다. 사용자 앱은 자동 교체하지 않았다.

## 요구사항 대조 — 2026-11-02, 1.0.4 기준

사용자 요청으로 goals와 현재 제품 코드의 연결 경로를 대조했다. 새 실제 AI 시험은 하지 않았다. 아래는 요구사항 문장 수나 작업량 비율이 아니라 **미완료 기능 묶음10개**다. 초기 출시 완료와 후속 요구 전체 완료는 구분한다.

1. **부분 구현 — 외부 CLI 세션 가져오기:** 같은 기기의 Claude 검색/복사/등록과 native ID 전달은 구현됐다. 회사 실제 기록이 검색되지 않는 원인과 로그인된 Claude의 실제 맥락 답변은 확인 안 함이다. 외부 Codex 가져오기는 안 된다.
2. **안 된다 — 같은 AI 다중 계정:** 계정별 연결 ID/별칭·독립 프로필·세션별 계정 선택은 미구현이다.
3. **안 된다 — 통합 MCP 관리:** 기존 설정 탐색·범위별 선택·연결/인증 상태·세션 적용 관리가 없다. 일반 대화 기능 자체는 1.0.4에 구현됐으며 MCP 관리와 구분한다.
4. **부분 구현 — AI 세부 옵션:** settings.mjs는 model/effort만 변경한다. 접근 수준·Fast·Plan 전용 제어와 지원 정보 통합은 미구현이다. Claude 모델 목록은 프리셋이며 실제 계정별 목록이 아니다.
5. **안 된다 — 제품의 Computer Use/보안 입력 통합:** 실행 화면·OS 권한·중단 동선과 실제 로그인 입력 어댑터가 없다. secure-login/server.mjs는 고정 내장 시험값만 처리하는 createTrialServer이며 외부 로그인 지원이 아니다. CLI 도구가 개별적으로 실행할 수 있는지와 제품의 통합 지원은 구분한다.
6. **안 된다 — D5 로컬 A→B→A:** 세션 이식/버전·분기 비교/경로 매핑과 원격 Git 변경의 최신 fetch 기반 확인 흐름이 없다. 현재 Git 요약의 ahead/behind는 로컬에 있는 tracking 정보이며 다른 기기의 최신 변경 탐지 완료가 아니다.
7. **부분 구현 — 선택형 Git 자동화:** 단일 저장소 브랜치/worktree 기본 선택·생성은 있으나 사용자→프로젝트→세션 정책, 테스트 반영·PR/병합·완료 정리 흐름은 없다.
8. **안 된다 — 여러 Git 저장소 작업 묶음:** 저장소별 worktree·경로/환경/포트·반영 대상·부분 성공 관리를 묶는 기능은 없다.
9. **안 된다 — QR 연결:** 짧은 일회용 코드 기반 서버 연결은 미구현이다.
10. **부분 구현 — 다른 AI로 인계:** 고정 시험 대상의 인계 코드는 있지만 배포 앱의 Runner 작업공간 경로에서는 /config의 newHandoff가 false다(server.mjs). 현재 제품에서 제공되는 기능으로 계산하지 않는다. 일반 세션 재개와 구분한다.

추가 현재 제약: 인증 자동 갱신/기기별 취소는 미지원이며, 업데이트는 검증된 DMG 다운로드 후 수동 교체다. 무인 교체/재시작은 명시된 별도 후속이다. 모바일 바이너리·공개 인터넷 중계·유료 공증은 제외한 범위이므로 누락으로 계산하지 않는다.

**확인 안 함 — 구현과 별도 검증 잔여:** 회사 Claude 실제 검색/맥락 복원, 일반 대화 신규 흐름의 실제 AI/MCP 응답, 깨끗한 두 번째 Mac/앱 덮어쓰기 후 데이터 보존, 별도 LAN HTTPS·장시간 절전, 실제 Codex 질문 UI·하위 에이전트 전체 수명주기. 기존 시험 기록이나 자동 검사256개를 이 항목의 성공으로 대체하지 않는다. 다음 구현 범위는 사용자와 정하며 이번 점검에서 후속 기능을 자동 착수하지 않는다.

- 사용자 요청: 회사 로컬 모드에서 MARICODE 밖의 기존 Claude 세션을 가져올 수 없었다. 이전 요구사항에 있던 원래 세션 이어가기의 미충족 부분이며 다른 기기 간 이식(D5)과 구분해 goals에 보완했다.

- **확인 안 함 — 실기:** 깨끗한 release 첫 실행/Applications 덮어쓰기·정식 데이터 보존, 두 번째 Mac, 별도 LAN HTTPS·장시간 절전 복귀, 실제 Codex 질문 UI·하위 에이전트 전체 수명주기.
