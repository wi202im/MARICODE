# MARICODE 인계

상태는 이 파일, 요구사항은 [goals.md](goals.md), 이전 과정은 Git 로그를 따른다.

## 지금 상태 — 2026-11-01

**MARICODE 1.0.0: D3 완료, D4 배포 준비 중. 공개 출시 완료가 아니다.**

- 이 저장소는 선별한 제품 코드·테스트·설치/사용/빌드 안내만 포함한다. 기존 비공개 개발 이력·개인 자료·계정·대화·기기 설정은 복사하지 않았다.
- GitHub 저장소는 private, `v1.0.0` 릴리스는 draft다. 사용자 결정은 자료를 준비한 뒤 저장소와 릴리스를 함께 공개하는 것이다. 현재 공개 전환/발행 권한으로 확대하지 않는다.
- 릴리스 후보 기준은 초기 제품 커밋 `1bcc7d4`. DMG, 제품 소스, Bun/WebKit 소스, 체크섬, 빌드/사용 안내, 고지, 라이선스 총9개 파일의 원격 크기·SHA-256 일치를 확인했다. 이번 요구사항/인계 문서 추가는 제품 바이너리를 바꾸지 않는다. 제품 변경 시 후보 소스·DMG·초안 대상을 함께 갱신한다.
- 기존 저장소 바깥의 독립 체크아웃을 준비했다. 이후 제품 작업의 시작점으로 사용할 수 있으며 두 저장소에서 제품을 병행 수정하거나 자동 동기화하지 않는다. 기존 실행 환경의 이관은 아직 끝나지 않았다.

## 된다 — 확인한 범위

- 이전 실제 시험: 로컬/서버/원격 역할, Claude/Codex 공식 계정 연결과 응답, 같은 엔진 세션 종료·재개, Mac+Linux 다중 서버·Tailscale 연결 및 단절 복구.
- 이전 실제 Mac 개발 앱: 프로젝트/작업공간/세션 흐름, Claude 질문·이번 승인·거절, Finder 파일/이미지 붙여넣기·첨부 전송·제거·파일 선택, 기존 대화·설정 보존과 사용자 확인 Dock 아이콘. 초안은 메모리이며 종료 시 자동 보존 기능으로 과장하지 않는다.
- 릴리스 DMG: 이미지 검증, 마운트·앱 복사, ad-hoc deep/strict 서명 검증, 복사한 번들의 새 데이터 실제 Hub 시작/인증/종료/재시작. AI 계정은 복사하지 않았다.
- 이번 독립 체크아웃: Node 26.12.1에서 자동 테스트237개 통과, 재사용한 고정 Node/HAPI 0.33.3으로 release 앱 빌드·ad-hoc deep/strict 서명 검증. 새 번들만으로 격리된 실제 HAPI 인증·빈 세션 조회·workspace HTTP200·정상 종료도 확인했다. 이 결과는 GUI 설치/기존 데이터 이관 시험과 구분한다.

## 안 된다 / 확인 안 함

- **안 된다:** 지금 초기 배포 완료로 선언. 포함 의존성 고지 정리와 아래 설치 실기 범위가 남았다.
- **확인 안 함 — 고지:** 기존 고지의 본문 누락10개 목록에는 선택/peer 의존성이 포함된다.10개 모두 HAPI 배포 바이너리에 실제 포함됐다고 확정하지 않았다. Bun/WebKit 소스는 확보·업로드했지만 수정본 교체/재링크 제공 자료의 충분성은 확인 안 함이다. 실제 배포 대상 중심으로 범위를 좁힌다.
- **확인 안 함 — 실기:** 현재 release DMG의 native 첫 창/Applications 덮어쓰기·기존 배포 데이터 보존, 깨끗한 두 번째 Mac, 별도 LAN HTTPS·장시간 절전 복귀, 실제 Codex 질문 UI와 하위 에이전트 전체 수명주기. 이전 개발 앱/HTTP 시험을 이 항목의 성공으로 대체하지 않는다.
- **미구현/미완료 후속:** 같은 AI의 다중 구독 계정 선택, 통합 MCP 관리, 폴더 없는 범용 대화, 선택형 Git 자동화·여러 저장소 작업 묶음, D5 로컬 기기 간 native 세션 이식, QR 연결, 실제 보안 로그인 입력 연동. 세부 목표는 goals를 따른다.

## 다음 할 일

1. 현재 포함 바이너리 기준으로 필요한 고지·소스 제공 범위를 정리한다. 전체 선택 의존성 조사/전체 재빌드로 확대하지 않는다.
2. 현재 release 설치 후보의 native 첫 창/실제 설치·교체 미확인 범위를 확인한다. 실행 중인 사용자 작업·초안을 임의 종료하지 않는다.
3. 제품 변경이 필요하면 이 저장소에서 구현·검증하고 소스/DMG/초안을 함께 갱신한다. 공개 전환은 준비 상태 보고 후 사용자 지시에 따른다.

## 이전 저장소 정리 경계

독립 소스 체크아웃과 기존 Git 전체 참조 백업의 별도 복원·무결성 검사는 완료했다. 기존 GitHub 부가 자료도 비공개 위치에 보존했다. 백업은 제품 공개 파일에 넣지 않는다.

**기존 폴더 삭제는 아직 안 된다.** Git 제외 실행 데이터·기존 앱/서버·절대 경로 설정이 남아 있다. 새 체크아웃의 독립 실행 성공은 기존 사용자 세션의 데이터 이관 성공을 뜻하지 않는다. 실제 이관 전에는 사용자 작업/메모리 초안 보호, 일관된 DB·계정/설정 백업, 경로 변경과 재개 검증이 필요하다. 외부 기기의 미푸시 커밋·미커밋 자료도 이번 로컬 Git 백업에 포함되지 않는다.

기존 원격 저장소와 로컬 실행 폴더 삭제는 별개다. 삭제·archive·프로세스 종료·개인 데이터 공개는 이번 사전 준비에 포함하지 않았다. 해당 기기별 경로와 보존 위치는 기존 비공개 인계에 남겼다.
