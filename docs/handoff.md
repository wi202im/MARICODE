### 1.0.4 배포 준비 — 세션 시작 흐름

- 사용자 피드백에 따라 기존 Claude 검색은 작업공간 기준으로 패널을 열 때 자동 실행한다. 별도 프로필 경로는 고급 옵션으로 내리고 작업 폴더/실제 검색 위치를 표시한다. 저장소 없음·프로젝트 기록 없음·빈 기록·형식 제외를 구분한다. 회사 기록이 비는 실제 원인은 아직 확정하지 않았고 회사 파일/원문을 가져오지 않았다.
- 새 작업은 같은 서버·정확히 같은 작업공간의 최근 AI를 선택한다. 모델·추론을 조회해 안내하고 새 세션 생성 후 지원되는 값만 기존 설정 API/미확인 보호로 적용한다. 사용자가 AI를 바꾸면 승계를 해제한다. 계정·승인·액세스 수준은 복제하지 않는다.
- 빈 화면과 새 작업에 **일반 대화**를 추가했다. 프로젝트 폴더를 지정하지 않고 AI를 선택해 채팅으로 들어간다. CLI용 폴더는 앱 전용 데이터의 별도 경로에 두며 마지막 프로젝트/홈을 쓰지 않는다. 일반 대화의 등록은 인증 뒤 명시 버튼으로만 수행하고 반복 준비는 같은 공간을 반환한다. Runner 시작 시 전용 폴더를 허용 목록에 포함해 일반 대화 때문에 기존 프로젝트 실행을 종료하지 않게 했다. 통합 MCP 관리/자동 연결은 여전히 후속이다.
- **된다 — 자동 검사256개.** 기존 검사에 검색 실패 유형 구분, 정확한 작업공간의 최신 AI, 일반 대화 인증·교차 출처·임의 폴더 차단, 중복 준비·중복 생성, 기존 활성 세션 옆 일반 대화 생성/Runner 무재시작, 심볼릭 링크 거부를 추가했다.
- **된다 — 제품 웹 UI + 합성 Hub.** 최근 Claude/sonnet/high 자동 선택→새 세션의 sonnet/high 반영, 기존 기록 자동 검색/고급 저장 위치 검색, 기존 프로젝트 대화와 일반 대화 동시 유지, 프로젝트0개 초기 화면에서 폴더 선택 없이 일반 Claude 세션 생성/채팅 진입을 확인했다. UI 시험 중 연결 전 모델 설정을 건너뛰던 문제도 수정해 재시험했다.
- **확인 안 함:** 회사의 실제 기존 기록 발견·맥락 답변, 이번 일반 대화에서 실제 AI/MCP 응답, 새 DMG 설치. 사용자 설치 앱/계정은 변경하지 않았다. 공개 배포는 여전히1.0.3이며 이번 수정의 DMG/릴리스는 아직 만들지 않았다.
- **다음:** 사용자 요청으로 1.0.4 버전/DMG·공개 릴리스를 준비한다. 회사 검색 실패는 새 화면의 진단 결과로 이어 확인하되 회사 원문/자료를 수집하지 않는다.

### 이전 수정 — 기존 Claude Code 기록 가져오기

- 사용자 요청: 회사 로컬 모드에서 MARICODE 밖의 기존 Claude 세션을 가져올 수 없었다. 이전 요구사항에 있던 원래 세션 이어가기의 미충족 부분이며 다른 기기 간 이식(D5)과 구분해 goals에 보완했다.
- 새 작업 → 프로젝트/작업공간 → Claude → **기존 Claude 세션 가져오기**. 기본 `~/.claude` 또는 명시한 설정 폴더에서 정확히 같은 cwd의 기록을 찾는다. 제목/첫 입력 일부·수정 시각·메시지 수로 선택하고 복사본 가져오기를 확인한다. 프로젝트/브랜치/worktree를 묵시적으로 바꾸지 않는다.
- 원본 JSONL과 해당 subagents JSONL만 전용 Claude 프로필에 복사하고, HAPI 0.33.3의 CLI 세션 등록 API로 inactive 세션을 등록한다. 기존 `/resume` 경로가 원래 native ID를 전달한다. HAPI 소스는 수정하지 않았다. 원본은 보존하며 이후 양쪽 대화는 동기화되지 않는다. 계정·MCP·설정·첨부 파일·메모리는 복사하지 않는다.
- HAPI는 재개 이전 기록을 채팅에 재전송하지 않으므로, 가져온 시점의 텍스트를 별도 **가져온 이전 기록**에서 50개씩 읽는다. 도구/첨부는 요약하고 과거 승인을 재실행하지 않는다. 이력 표시와 엔진 맥락 재개를 구분한다.
- **된다 — 자동 검사251개.** 폴더 불일치·원본 변경·심볼릭 링크·기존 대상 덮어쓰기 차단, 선택 파일만 복사, 불변 이력/페이지 조회, 등록 응답 유실 후 조회만 수행, 잘못된 native ID 응답 거부, 동시 등록 잠금, 인증/교차 출처/원격 전달 차단. 가져오기와 결과 확인은 앱 종료 보호의 작업 잠금에도 포함한다. 결과 확인은 Runner를 새로 시작하지 않는다.
- **된다 — 실제 HAPI/제품 웹 UI.** 격리한 Hub·Runner와 합성 Claude 기록으로 검색→선택→등록→채팅 진입, 이전 한글 기록 펼치기, 새로고침 후 같은 세션/기록 조회를 확인했다. 실제 HAPI/Claude CLI 실행에서 원래 native ID로 재개됐고, CLI 실행 인자의 `--resume` 대상도 일치했다. 원본 보존과 별도 웹 소유자의 읽기 전용 등록 결과 확인도 확인했다. 시험 세션은 정상 archive했고 전용 Hub/Runner·시험 탭을 모두 정상 종료했다. 사용자 앱/계정/회사 세션은 변경하지 않았다.
- **확인 안 함 — 구독 로그인된 Claude의 실제 맥락 답변.** 격리 프로필에 인증이 없어 실제 CLI 응답은 로그인 필요였다. native ID 전달/등록 성공을 실제 모델의 맥락 답변 성공으로 표시하지 않는다. 회사 기기의 실제 기록, 대규모/다양한 버전 기록, 새 DMG 설치도 확인 안 함이다. 외부 Codex 기록 가져오기와 D5 이식은 미구현이다.
- **다음:** 사용자 설치·실사용 피드백을 확인한다. 승인된 Claude 시험 프로필에서 실제 맥락 답변 검증은 여전히 남아 있으며 릴리스/README에 명시했다. 1.0.3부터 기능이 포함되고, 이전 설치 앱에는 업데이트가 필요하다. 사용 순서와 제한은 USER-GUIDE에 반영했다.
