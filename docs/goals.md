# Maricode — 제품 목표와 요구사항

제품 이름은 **Maricode**, 초기 배포 버전은 **1.0.0**이다. 표시 이름은 Maricode로 통일하고, 제목 영역에 현재 버전을 함께 표시한다. Dock 아이콘 이름도 Maricode로 표시되도록 앱 번들 파일명은 `Maricode.app`으로 맞춘다. 업데이트 호환성을 위해 기존 앱 식별자·저장 경로·DMG 배포 파일명은 유지한다. 아래는 요구사항이며 실제 구현/검증 상태는 `handoff.md`를 따른다. 미구현 요구를 출시 기능으로 표시하지 않는다.

## 범위와 구조

독립 개발툴로 Claude Code와 Codex의 채팅·작업 흐름·파일·승인·세션 재개를 제공한다. 자체 개인비서, 상시 알림/예약 실행, 통합 모니터링은 별도 제품 범위다.

Mac 앱은 Swift/AppKit + WKWebView 안에서 공통 웹 UI를 제공한다. 연결은 REST/SSE → HAPI Hub/Runner → AI 실행 엔진이다. HAPI 공개 기능을 우선 활용하고 필요한 보완만 작게 한다. 기존 외부 도구에 플러그인을 설치하거나 다른 앱의 운영 서버를 교체하지 않는다.

Claude/Codex 구독 로그인을 우선하며 API 키 과금만 되는 경로를 강제하지 않는다. 서버 접속 인증과 AI 계정 인증은 별개다. 실패 시 다른 AI·계정·유료 API로 자동 대체하지 않는다.

## 컴퓨터 역할과 데이터 경계

- **로컬:** 파일·세션·실행 상태가 해당 컴퓨터에 남는다. 외부 클라이언트에 직접 공개하지 않는다. 다른 로컬 기기로 이어가기는 별도의 명시적 세션 이식 기능이다.
- **서버:** 로컬 기능을 포함하고, 켜져 있을 때 허용된 사설망 클라이언트가 같은 작업을 이어간다. 파일·AI 실행·연산은 서버에 남는다.
- **원격:** 로컬 소스나 AI 설치 없이 서버에 접속한다. 서버를 기억하고 기존 작업을 이어가며, 연결 단절 시 로컬로 대신 실행하지 않는다.
- 로컬+원격, 서버+원격과 여러 원격 서버의 동시 작업을 지원한다. 서버별 인증·선택·입력·미확인 요청·재연결을 분리하고 서버 하나의 장애가 다른 작업을 중단시키지 않게 한다.
- 같은 망은 LAN·사내망·Tailscale을 포함한다. 공개 인터넷 릴레이/Funnel은 초기 범위 밖이다. 검색 결과 자체가 접속 권한은 아니다.
- 역할 선택은 회사/개인 자료의 소유·접근 정책을 바꾸지 않는다. 회사 자료를 개인 서버로 중계하지 않는다.

## 프로젝트·작업공간·세션

| 단위 | 책임 |
|---|---|
| 프로젝트 | 이름과 기준 폴더. 단일 Git 또는 여러 독립 저장소의 상위 폴더 |
| 작업공간 | 정확한 실행 폴더/체크아웃/worktree. 별도의 안정 ID |
| 세션 | 작업공간에 속한 AI 대화·계정 연결·모델 옵션·실행 상태 |

- 내부 계층은 컴퓨터 → 프로젝트 → 작업공간 → 세션이다. 왼쪽 목록에서는 기본 작업공간만 하나 있으면 중간 행을 숨겨 프로젝트 → 세션으로 표시한다. 작업공간이 여러 개거나 머신/폴더 구분이 필요하면 계층을 유지한다. 검색/보기 필터로 하나만 남았다는 이유로 계층을 합치지 않는다. 프로젝트 등록 시 기본 작업공간을 준비한다. 작업공간과 worktree는 동의어가 아니다.
- 최초 실행은 역할만 선택한 뒤 빈 레이아웃을 연다. 프로젝트·AI 계정을 모두 연결하도록 강제하지 않는다.
- 중앙 ‘대화 추가’에서 새 대화/기존 대화 가져오기를 먼저 선택한다. 프로젝트 선택/추가 → 필요한 작업 폴더·선택 Git 옵션 → AI/계정 → 대화로 이어진다. 기본 작업공간 하나면 선택칸을 생략한다. 새 대화 대상은 현재 대화와 분리해 목록 갱신에 흔들리지 않게 한다.
- ＋는 대화 추가를 뜻한다. 기본 공간 하나면 프로젝트 행에, 여러 공간이면 각 작업공간 행에만 두며 중복 ＋를 표시하지 않는다. 프로젝트 등록과 선택적인 워크트리 생성은 별도 동작이다.
- 대화는 사용자 지정 이름·실제 AI 제목·첫 입력으로 식별하고, 제목 정보가 없으면 짧은 ID로 구분한다. AI 종류와 실행 상태는 부가 정보로 표시한다. 가져온 이전 이력과 현재 앱의 이력 수를 구분한다.
- 새 세션의 기본 AI는 같은 서버·정확히 같은 작업공간의 최근 세션에서 가져온다. 모델·추론 값도 조회해 새 세션의 지원 목록에 있는 값만 기존 설정 API로 적용한다. 사용자의 AI 선택은 우선하며 계정·승인·접근 권한을 자동 복제하지 않는다. 생성/설정 미확인은 자동 재전송하지 않는다.
- 같은 작업공간의 세션은 폴더와 브랜치를 공유한다. 독립 파일 변경에는 별도 worktree를 선택한다. 세션 종료가 폴더·브랜치·대화 삭제는 아니다.
- Git 없는 폴더와 현재 폴더 그대로 작업하기를 지원한다. 새 worktree는 선택 커밋에서 만들고 미커밋 파일을 자동 복사하지 않는다.
- 브랜치 변경은 미커밋 변경·다른 worktree 점유·활성 작업을 보호한다. Git 준비/세션 생성을 같은 요청에 결속하고 일부 성공·응답 유실을 자동 반복하지 않는다.
- 프로젝트 등록은 임의 경로 실행 권한이 아니다. 등록 ID로 실행 폴더를 확인한다. Runner 변경은 활성/미확인 세션을 보호하고 기존 대화/머신 ID를 보존한다.
- 프로젝트/작업공간/세션 표시 이름 변경과 등록 해제/숨김·복원을 제공하되 실제 파일·Git·대화를 지우지 않는다. 활성/승인 대기·미확인 작업의 제거를 차단한다.

## 작업 화면·채팅 UX

- 대화 준비 화면은 시작 목적·주요 실행 버튼·오류를 보이게 유지하고 선택 영역만 스크롤한다. 반복 경로/설명은 줄이고 기술 정보·미지원 기능이 핵심 동작을 가리지 않게 한다.
- 앱 안에서 작업하며 외부 브라우저 관리 실행기를 최종 로컬 작업 화면으로 쓰지 않는다.
- 왼쪽은 프로젝트/작업공간/세션 계층과 보기 설정, 중앙은 채팅·입력, 오른쪽은 파일·도구·세션 정보다. 대화/도구/파일로 중앙 채팅을 교체하지 않는다.
- 컴퓨터 전환은 왼쪽 하단 호스트 메뉴, 현재 컴퓨터·연결 상태는 제목줄 오른쪽이다. 로컬+서버는 한 화면을 공유하고 원격 컴퓨터별 화면을 보존한다.
- 제목줄 좌우 토글로 전체 사이드바를 접고 펼친다. 설정/연결 관리는 같은 창에서 열고 뒤로가기로 대화·선택·초안을 보존한다.
- 큰 로고/정보 띠를 두지 않고 제목줄의 작은 Maricode와 설치된 앱 버전, 중앙 세션 제목, 우측 상세로 역할을 나눈다. 세 영역은 창 높이를 채우고 하단 상태줄은32px로 맞춘다.
- 로컬 전용에는 토큰 공유/서버 공개 UI를 숨긴다. 원격 선택 시 로컬 실행 준비·공유 설정을 숨긴다. UI 숨김은 서버 권한 검사를 대체하지 않는다.
- 한글 채팅, 접을 수 있는 연속 도구 활동, 파일 변경 전/후와 도구 결과, 메시지 시각/관찰된 경과 시간, 계획과 부모가 식별된 하위 작업을 표시한다. 시작 요청 성공을 하위 작업 완료로 표시하지 않는다.
- 승인·질문은 입력창 가까이에 요약·접힌 상세·선택지를 둔다. 이번 요청/이번 응답/세션 허용을 실제 엔진 의미대로 표시한다. 서버가 요청 내용·AI·범위·최신 상태를 다시 확인하고 중복 승인을 막는다.
- Git 하단은 읽기 전용 조회다. 브랜치·변경 수·커밋·worktree를 표시하며 실패를 변경 없음으로 바꾸거나 조회만으로 fetch/checkout을 실행하지 않는다.
- 파일 선택·드롭·클립보드의 실제 파일 데이터, 이미지 미리보기·개별 제거를 지원한다. 경로 문자열은 파일 접근 권한이 아니다. 파일당5MB/합계10MB/최대5개이며 보내기를 누를 때만 업로드한다.
- 텍스트/첨부 초안은 현재 창의 세션별 메모리에 남으며 창 종료/새로고침 뒤 복원하지 않는다. 업로드 미확인은 자동 재전송하지 않는다.
- Paseo 공개 UI의 흐름/디자인을 참고한 부분은 출처·라이선스를 유지한다. 브랜드·서버·전체 프레임워크를 도입하지 않는다.

## 세션 연속성과 실행 안전성

정상 종료 후 Claude/Codex 원래 세션으로 재개하는 것과, 다른 AI에 최근 텍스트를 전달해 새 세션을 만드는 것은 구분한다. 새 인계 세션에는 출처·전달 범위를 표시한다. 긴 대화 전체가 전달됐다고 보장하지 않는다.

같은 컴퓨터에서 MARICODE 밖의 Claude Code로 진행하던 기존 대화를 찾고 가져오는 것도 요구사항이다. MARICODE에서 만든 세션의 재개만으로 이 요구를 충족했다고 보지 않으며, 다른 컴퓨터 간 이식인 D5와 구분한다. 먼저 로컬 Claude를 지원한다. CLI에서 폴더로 이동한 뒤 대화를 고르는 것처럼 작업공간 선택 → 기존 세션 목록으로 이어져야 한다. 패널을 열면 해당 폴더의 기록을 자동 검색한다. 기록 저장 위치는 명시 선택, CLI 환경변수, 셸 설정의 단일 정적 경로, 기본 프로필 순으로 확인하며 사용한 위치와 출처를 표시한다. 셸 스크립트·별칭·함수는 실행하지 않고 동적/복수 후보는 직접 선택하도록 안내한다. Mac 앱에서는 숨김 폴더가 보이는 폴더 선택창을 제공하고 선택 후 자동 검색한다. 경로 직접 입력은 보조 수단으로 두며 ~/ 경로도 지원한다. 프로필 없음·해당 폴더 기록 없음·형식 제외를 구분하고 검색 위치를 확인할 수 있어야 한다. 등록한 작업공간과 원래 실행 폴더가 일치하는 기록을 기본 `~/.claude` 또는 사용자가 지정한 `CLAUDE_CONFIG_DIR`에서 찾고, 제목/첫 입력 일부·수정 시각으로 선택한다. 원래 기록은 보존하고 전용 프로필의 복사본을 같은 native 세션 ID로 재개한다. 이후 원본과 복사본은 분기되며 자동 동기화하지 않는다. 작업 브랜치/워크트리는 가져오기만으로 변경하지 않는다.

가져오기는 로컬 앱/실행 컴퓨터의 loopback 화면에서만 허용한다. 회사 기록을 외부 서버로 탐색·전송하지 않는다. 계정·설정·MCP·메모리·첨부 파일을 묵시적으로 복사하지 않고 MARICODE에 명시적으로 연결한 계정을 사용한다. 필요한 환경/파일은 별도 확인한다. 원본 변경·잘못된 cwd·심볼릭 링크·기존 대상 기록을 보호하고 등록 미확인은 재전송하지 않는다. 이전 기록은 가져온 시점의 읽기 전용 텍스트로 구분하며 과거 도구 요청을 새 승인으로 재현하지 않는다. 원래 엔진의 맥락 재개와 화면의 이력 조회는 따로 검증한다. Codex 외부 기록도 같은 가져오기 화면에서 AI를 Codex로 골라 가져온다. 원래 Codex 기록 폴더(기본 `~/.codex`)에서 해당 프로젝트 폴더에서 시작한 최상위 스레드만 보여주고, 선택한 rollout 파일 하나만 전용 Codex 프로필로 복사해 같은 스레드 ID로 재개한다. 인증·설정·MCP·상태 DB는 복사하지 않는다. 이전 대화는 재개 시 엔진이 다시 채우는 기록으로 표시하며 중복 표시하지 않는다.

새 세션 만들기와 기존 세션 가져오기는 처음부터 별도 진입으로 구분한다. 가져오기 화면에 새 세션 생성 버튼을 함께 두지 않는다. 등록과 이전 기록 조회가 확인된 뒤 가져온 대화를 열며, 실패/미확인은 해당 화면에서 설명한다. 등록 후 화면 열기 실패는 동일 ID로 다시 열고 복사·등록을 반복하지 않는다. 복사 방식 안내는 표시하되 버튼을 막는 확인 체크박스를 요구하지 않는다. 가져올 대화 콤보박스 옆 새로고침 아이콘과 마지막 확인 시각을 제공한다.

같은 native 세션이 프로젝트 루트에서 시작해 하위 폴더에서 이어진 정상 이력은 가져올 수 있어야 한다. 다른 프로젝트·세션 ID의 기록은 자동 혼합하지 않는다. 실패 시 경로·대화 원문 없이 행 번호와 원인 종류를 구분하고, 통과시키기 위해 원본 행을 삭제하거나 cwd/ID를 덮어쓰지 않는다.

가져오기 직후 이전 대화를 자동으로 펼쳐 최근 내용부터 보여준다. 새 메시지와 하나의 스크롤 영역을 사용하며 오래된 기록은 추가로 조회한다. 사용자는 대화 내용을 보고 올바른 세션을 가져왔는지 확인할 수 있어야 한다. 이 표시만으로 엔진의 맥락 재개 성공을 선언하지 않는다. 등록이 끝나고 연결·대상 세션 상태가 재개 가능하면 수동 클릭 없이 바로 실행 재개까지 이어간다. 연결이 안 됐거나 이미 실행 중이거나 자동 재개가 실패하면 기존처럼 수동 재개 버튼으로 안내한다.

엔진 실행 실패·재시도·대기 메시지 폐기는 채팅에 원인과 함께 표시한다. '접수 확인'만 남기고 조용히 재시도하게 두지 않는다. 폐기된 메시지는 자동 재전송하지 않고 원인 해결 후 다시 보내도록 안내한다.

재연결은 이력·선택을 복구하되 접수 불명 요청을 재전송하지 않는다. 실행 중·승인 대기·생성/재개 미확인 상태에서 종료/업데이트/Runner 변경을 보호한다. 살아 있는 소유 불명 프로세스를 자동 인수·종료하지 않는다. 제한된 잠금 복구도 프로세스 종료와 기록 경계를 확인한 경우만 한다.

내부 심볼릭 링크를 탐색하되 프로젝트 밖 링크 접근은 별도로 허용된 범위가 필요하다. 경로·권한 실패를 숨기거나 다른 폴더로 대신 실행하지 않는다.

## AI 계정·세부 기능 — 후속 범위 포함

- 정상 연결된 AI는 새 대화 화면에서 상태만 표시하고 설정/로그인 버튼은 연결 문제를 해결할 때 노출한다. 상세 계정 관리는 접힌 영역에서 제공한다. 조회 실패를 연결 성공으로 처리하지 않는다.
- 한 AI 계정만 있어도 시작할 수 있다. 미설치/미로그인은 첫 사용 시 공식 연결을 안내한다. 공식 로그인 성공 후 실행 환경에서 상태를 재조회한다.
- 같은 AI의 여러 계정을 실행 컴퓨터별 고유 연결 ID·별칭으로 등록하고 새 세션마다 선택하는 것이 목표다. 계정별 인증/설정/세션 저장소를 분리하고 실행 중 계정은 고정한다. 현재 다중 구독 계정 실행은 미구현/미확인이다.
- 모델·추론/사고·액세스 수준·속도·계획 모드를 최소 공통분모로 제한하지 않는다. 엔진/버전/모델/계정별 지원 정보를 확인하고 요청값과 실제값, 값의 출처, 적용 범위/시점을 구분한다.
- 채팅은 Enter로 전송하고 Shift+Enter로 줄바꿈한다. 한글 등 IME 조합 확정과 키 반복은 전송으로 처리하지 않는다. 키보드 전송도 실행 중·승인 대기·접수 미확인 보호를 따른다.
- Bypass 등 선택한 액세스 모드는 사용자가 직접 변경하기 전까지 같은 세션의 새로고침·재연결·종료 후 재개에서도 유지한다. 전송 완료나 재개만으로 기본 모드에 자동 복귀하지 않는다. 다른 새 세션의 권한을 자동 확대하는 것과는 구분한다.
- 입력창에서 실행 AI가 지원하는 세션별 액세스 모드를 선택·적용한다. Claude의 기본/편집 자동 허용/자동 판단/Bypass/계획, Codex의 기본/읽기 전용/자동 검토/전체 접근은 HAPI0.33.3 경로로 전달한다. 실제 지원 여부는 해당 CLI에 달려 있으며 현재 서버 보고값·설명·적용 대상을 표시한다. 오래된 설정/다른 AI/실행 중/승인 대기 변경을 거부하고 결과 미확인은 재전송하지 않는다. 새 세션의 최근 모델·추론 승계에 액세스 정책은 포함하지 않는다.
- 권한 정책·샌드박스와 단발 도구 승인은 별개다. 권한 확대는 대상 세션/범위를 명시한다. Fast를 낮은 effort로 흉내 내거나 추가 과금을 자동으로 켜지 않는다. Plan을 모든 도구의 강제 읽기 전용으로 보장하지 않는다.
- 옵션 지원은 CLI 자체 → HAPI 전달 → 우리 UI 노출의 세 단계로 판정한다. 지원 경로가 없으면 미지원 사유를 표시하며 일반 채팅으로 슬래시 명령을 보내 적용됐다고 가정하지 않는다.
- Computer Use는 실행 머신의 도구·화면/브라우저 연결·OS 권한·중단 동선이 필요하다. 어느 머신을 조작하는지 표시한다.
- 웹 로그인 비밀번호/OTP는 일반 채팅·도구 결과·로그로 받지 않는다. 전용 입력은 머신·사이트·세션·요청을 고정하고 모델 관찰/저장 차단을 검증해야 한다. 지원하지 않으면 사용자 직접 입력으로 넘긴다. 보안 입력 시제품을 실제 외부 로그인 지원으로 표시하지 않는다.

## MCP와 범용 대화 — 후속 요구

실행 머신의 기존 Claude/Codex MCP 설정을 먼저 확인하고, 공통 정의/엔진별 인증·지원 차이를 분리한다. 사용자/프로젝트/세션 범위에서 선택하되 전역 설정을 덮어쓰거나 다른 세션을 묵시적으로 변경하지 않는다. HTTP MCP와 로컬 stdio를 구분하고 접속 가능 여부는 화면 기기가 아닌 실행 머신 기준이다. 사내 MCP 결과의 모델 전달도 조직 정책을 따른다.

설정됨/비활성/인증 필요/연결 실패/도구 사용 가능을 구분한다. OAuth·자격증명을 엔진/기기 사이에 자동 공유하지 않는다. 실제 세션별 적용과 재시작 필요 여부를 확인한다.

폴더/브랜치/worktree 없이 AI·선택 MCP로 일정/업무/데이터를 조회하는 대화도 목표다. 엔진이 cwd를 요구하면 전용 비프로젝트 폴더를 사용하며 마지막 프로젝트나 홈을 묵시적으로 선택하지 않는다. Git 자동화, 파일 권한, MCP 변경 권한은 독립적이다. 자동화 없음이 읽기 전용을 뜻하지 않는다. 새 작업의 ‘일반 대화’는 프로젝트·브랜치·워크트리 선택 없이 AI를 골라 시작한다. CLI용 폴더는 실행 컴퓨터의 앱 데이터 안에 따로 관리하고 일반 프로젝트와 분리된 ‘일반 대화’ 목록에 세션을 보관한다. 폴더 선택 생략은 도구 권한 제한이나 MCP 연결 완료를 뜻하지 않는다. 통합 MCP 관리는 별도 후속이다.

## 선택형 Git 자동화·여러 저장소 — 후속 요구

기본은 자동화 없음이다. 필요하면 작업 브랜치/worktree, 중간 테스트 반영, PR/직접 병합, 완료 후 정리를 각각 선택한다. 사용자 기본 → 프로젝트 명시값 → 세션 명시값 순으로 적용하고 해제도 명시적 선택이다. 변경은 이미 실행 중 작업에 소급하지 않는다.

상위 폴더 아래 독립 Git 저장소들이 있으면 저장소별 worktree를 묶되 하위 경로·환경/포트/의존성을 별도 준비한다. 테스트 반영과 최종 병합/운영 배포, 작업 정리는 다른 행동이다. 저장소별 대상 브랜치를 설정하며 특정 조직의 브랜치 이름을 하드코딩하지 않는다. 여러 저장소의 반영은 원자적이라고 가정하지 않으며 부분 성공을 일괄 재실행하지 않는다.

단일 저장소는 worktree 없이 작업 브랜치 → 작업/검토 → main 병합 확인 → 정리 흐름도 선택할 수 있다. 원격 브랜치 삭제만으로 로컬 worktree를 지우지 않는다. 정리 전 활성 실행·미커밋·미반영 커밋을 확인한다. 자동화 설정 자체는 모든 push/PR/배포의 포괄 승인이 아니다.

## 로컬 기기 간 이어가기 — D5 요구

로컬 기기 A → B → A로 작업을 옮길 때 Git 커밋과 AI 세션 버전을 각각 확인한다. 같은 서버의 원격 접속과 구분한다.

- 코드 변경은 허용된 remote에 push된 커밋을 fetch해 동일/앞섬/뒤처짐/분기/조회 실패로 표시한다. 다른 기기의 미푸시/미커밋 내용은 탐지하지 않는다. 알림만으로 checkout/merge/rebase를 실행하지 않는다.
- 엔진+세션 ID는 식별자이지 최신 대화 다운로드 수단이 아니다. 승인된 경로로 원래 기록·메타데이터를 전달하고 내용 버전/출처를 비교한다. Git 변화로 세션 변화를 추론하지 않는다.
- 양쪽에서 대화를 이어 썼다면 덮어쓰거나 임의 병합하지 않고 분기를 표시한다. 기기별 경로를 매핑하고 Git worktree 관리 파일을 통째로 복사하지 않는다. 인증정보는 이식하지 않는다.
- 이력 표시와 원래 엔진 재개는 별도로 검증한다. 세션 버전과 대응 커밋을 함께 확인하고 여러 저장소의 부분 반영을 전체 완료로 표시하지 않는다.
- 합성 A→B→A와 엔진별 실제 재개를 검증해야 하며 현재 구현/이식성은 확인 안 함이다.

## 배포·단계

D1/D2의 자체 UI·기본 작업 흐름과 D3의 역할·실행 환경·다중 서버 연결을 완성하고, D4 설치/배포 단계에서 1.0.0을 공개했다. D5 이식과 후속 기능을 초기 출시 완료 조건에 무조건 추가하지 않는다.

- 초기 배포는 Apple Silicon Mac DMG와 원격 웹/PWA다. 별도 모바일 바이너리·App Store 배포는 범위 밖이다. 초기판은 ad-hoc 서명으로 공개했으며, 2026-11-02 사용자 요청으로 기존 Apple Developer 멤버십을 이용한 Developer ID 서명·공증을 후속 배포에 추가한다. Apple의 Accepted 결과·티켓 부착·Gatekeeper 검증 전에 공증 완료로 표시하지 않는다. 기존 공개 첨부는 덮어쓰지 않는다.
- HAPI/Node는 앱에 포함한다. AI CLI 설치·공식 로그인·OS/네트워크 승인은 별도다. 앱이 전용 데이터/토큰/소유 프로세스를 관리하며 원격 전용은 로컬 AI가 불필요하다.
- 역할·AI 준비·프로젝트·세션·종료/업데이트를 실제로 확인한다. 다른 Mac/모바일/장시간 절전 미확인은 명시하고 시험 통과로 과장하지 않는다.
- 앱 교체 시 고정 Application Support/MARICODE의 설정·프로젝트·머신 ID·프로필·대화를 보존한다. 앱과 데이터는 분리하고 지원하지 않는 형식은 초기화하지 않는다. 개발 데이터는 자동 이관하지 않는다.
- 서버 접속 토큰은 앱에서 숨김/명시적 복사로 제공한다. 발급 인증의 기기 로그인 유지는 사용자 선택이며 원 액세스 토큰을 무조건 영구 저장하지 않는다. 현재 기기 보관은 JWT 만료/4시간 중 빠른 시각까지이며 자동 갱신·기기별 취소는 미지원이다.
- 향후 QR은 짧게 유효한 일회용 코드와 서버측 확인으로 연결하고 장기 토큰을 담지 않는다. QR은 사설망 접근 제약을 우회하지 않는다. 현재 미구현이다.
- 파일 접근 안내는 macOS 권한·파일 권한·AI 승인·허용 경로를 구분한다. OS 권한은 사용자가 직접 허용하며 전체 디스크 접근을 기본 요구하지 않는다.

- 설치 디스크에 한국어 첫 실행 안내와 개인정보 보호 및 보안 설정 바로가기를 제공한다. 앱이 차단되면 사용자가 해당 앱의 ‘그래도 열기’를 직접 승인한다. 업데이트 후에도 이 확인이 다시 필요할 수 있음을 표시하며 파일 접근 권한과 Gatekeeper 실행 차단을 구분한다.

## Paseo 대조 후속 후보 — 2026-11-02 사용자 결정
