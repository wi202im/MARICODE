Bonjour의 _merry._tcp 서비스 후보를 조회합니다. 방화벽·망 정책에 따라 검색되지 않을 수 있으며 직접 주소 등록도 가능합니다. 서비스 광고와 HTTPS 인증서 설정은 실행 머신에서 별도로 필요합니다.

Mac 로컬 실행 화면에서 사용할 수 있습니다.

서버 추가

Maricode 웹 화면의 기본 주소를 입력하세요. 경로·토큰은 넣지 않습니다. LAN 사설 IP·.local·Tailscale .ts.net을 지원하며 원격 주소는 HTTPS가 필요합니다.

목록에는 이름과 주소를 보관하며, 첫 로그인 성공 후 서버 ID도 별도로 보관합니다. 서버 ID가 바뀌면 자동으로 신뢰하지 않고 연결을 막습니다. 등록은 연결 성공이나 서버 신원 확인을 뜻하지 않습니다. LAN·Tailscale에 연결한 뒤 직접 열어 확인하세요. 브라우저 데이터 삭제 시 목록도 지워집니다. 이 화면에서는 세션 상태와 최근 대화를 조회합니다. 실행 중인 세션에 메시지를 보낼 수 있습니다. 실시간 연결은 선택한 서버·세션별로 켤 수 있습니다. 연결 복구 시 상태·이력만 조회하며 메시지를 다시 보내지 않습니다. 승인 대기 상세와 개별 허용·거절을 지원합니다. 응답 유실 시 결정을 재전송하지 않고 상태만 조회합니다. 자동 검색은 아직 지원하지 않습니다. 전송 확인 ID와 본문 해시는 이 탭에 보관하며, 접수 미확인 시 같은 탭에서 조회해 확인하세요. 탭을 닫거나 저장소를 지우면 이 기록은 유지되지 않습니다.
