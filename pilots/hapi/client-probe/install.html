지금 연결한 서버의 작업 화면을 홈 화면이나 Dock에서 바로 열 수 있습니다. 설치는 선택 사항이며 브라우저로 계속 사용해도 됩니다.

기기에서 설치

  • Android Chrome: 브라우저 메뉴 → ‘홈 화면에 추가’ 또는 ‘앱 설치’
  • iPhone·iPad Safari: 공유 → ‘홈 화면에 추가’
  • Mac Chrome: 주소창의 설치 아이콘 또는 메뉴의 설치 항목
  • Mac Safari: 파일 → ‘Dock에 추가’

메뉴 이름은 브라우저 버전에 따라 다를 수 있습니다. 원격 접속은 HTTPS 주소에서 설치하세요.

연결과 로그인

서버 컴퓨터가 켜져 있고 같은 LAN·사내망 또는 Tailscale에 연결되어 있어야 합니다. 이 앱은 오프라인 작업을 저장하거나 대신 실행하지 않습니다.

설치한 앱은 브라우저와 로그인 보관 공간이 다를 수 있어 첫 실행에 로그인이 필요할 수 있습니다. ‘이 기기에서 로그인 유지’는 발급 인증이 유효한 동안만 유지됩니다.

새 버전 사용

서버 앱을 업데이트한 뒤 작업 화면을 다시 열거나 새로고침하면 최신 화면을 받습니다. 진행 중인 입력을 마무리하고 요청의 접수 상태를 확인한 뒤 새로고침하세요. 설치 때문에 화면을 자동 새로고침하거나 요청을 다시 보내지는 않습니다.

현재 버전은 별도의 오프라인 캐시를 만들지 않습니다. 연결이 끊긴 상태에서 새로 열면 브라우저의 연결 오류 화면이 나올 수 있습니다.
