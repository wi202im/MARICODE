Maricode 1.1.0 — 설치·사용 안내

1.1.0 완전 초기화 전환 안내

이 버전은 첫 실행에서 이전 Maricode 앱 데이터를 한 번 정리합니다.
이전 앱과 공식 CLI 작업을 정상 종료한 뒤 Applications의 앱을 교체하세요.
프로젝트 등록·앱 대화/세션·연결·역할·로컬 Hub 자료가 삭제됩니다.
실제 작업 폴더와 외부 .claude/.claude-global/.codex 설정·원본 세션은 삭제하지 않습니다.
앱 내 브라우저의 로그인·화면 저장 자료도 한 번 비웁니다. 다른 브라우저·원격 서버는 그대로입니다.
정리 후 이 컴퓨터의 역할을 선택하고 기존 CLI를 다시 연결하세요.
완료 표식 이후 새 설정·대화는 보존하며,1.1.0을 다시 설치해도 반복 초기화하지 않습니다.
DMG 다운로드/열기만으로 정리하지 않으며 새 앱을 처음 실행할 때 처리합니다.

기존 대화의 /account 카드에서 공식 로그인 시작·완료 확인·대화 복귀를 할 수 있습니다.
암호와 인증 코드는 공식 CLI/브라우저에만 입력하세요. 연결 설정을 열어도 대화와 초안은 유지합니다.
로그인 확인만으로 메시지를 보내거나 종료된 대화를 자동 재개하지 않습니다.
/mcp의 인증/설정 적용 후 같은 세션을 재개할 수 있지만 실제 MCP 도구 연결은 별도 확인이 필요합니다.
명령 카드는 실행 컴퓨터의 로컬 화면에서만 제공하며 전체 CLI 터미널 화면을 내장하지는 않습니다.

공개 배포는 GitHub 릴리스의 DMG를 기준으로 합니다. 소스의 후속 수정은 다음 배포본부터 적용됩니다.
Apple Silicon Mac용이며 macOS 14 이상을 빌드 대상으로 합니다.
모든 macOS 버전과 깨끗한 Mac의 전체 설치를 검증한 것은 아닙니다.

1. 설치
DMG 안의 Maricode.app을 Applications에 복사하고 DMG를 꺼냅니다.
배포본의 서명·공증 여부와 첫 실행 절차는 DMG의 ‘처음 실행 안내.html’을 확인하세요.
공증본도 인터넷에서 다운로드한 앱인지 확인하는 macOS 창이 나올 수 있습니다.
시스템 보안을 일괄 해제하거나 다른 앱의 경고까지 무시하지 마세요.
HAPI와 Node는 포함되어 있습니다. Codex·Claude 설치와 공식 구독 로그인,
Tailscale 설치·가입·HTTPS 준비는 별도입니다.

2. 첫 실행과 프로젝트
처음에는 이 컴퓨터의 역할만 선택합니다. 로컬과 서버는 같은 컴퓨터 작업 공간이며,
원격 역할을 함께 사용하면 다른 컴퓨터의 작업도 함께 열 수 있습니다.
빈 작업 화면에서 ‘프로젝트 폴더 추가’로 기존 폴더를 등록하세요.
폴더 등록만으로 Git 브랜치나 AI 작업을 시작하지 않습니다.
프로젝트 → 작업공간 → 세션 순서로 목록이 표시됩니다.
＋의 ‘대화 추가’에서 새 대화 또는 기존 대화 가져오기를 고릅니다.
작업 폴더가 여러 개일 때만 폴더를 고른 뒤 AI를 선택합니다.
기본 작업공간은 등록한 폴더이며, Git 옵션에서 기존/새 worktree를 고를 수 있습니다.
브랜치나 worktree를 만들지 않고 현재 폴더에서 대화할 수도 있습니다.
미연결 AI는 ‘선택한 AI 연결’로 설치 경로를 등록하고, ‘AI 계정 연결’에서
‘기존 CLI 설정 찾기’로 터미널에서 사용하던 설정 위치를 확인하고 연결합니다.
필요할 때만 연결한 CLI의 공식 구독 로그인을 진행합니다. 인증정보를 복사하지 않습니다.
앱 전용 계정 생성·여러 프로필 전환은 제공하지 않습니다.
모델·추론 수준·액세스 모드는 세션을 연 뒤 대화 입력창에서 선택합니다.
Enter로 전송하고 Shift+Enter로 줄바꿈합니다. 한글 등 IME 조합 확정은
전송하지 않으며 실행 중·승인 대기·미확인 요청의 전송 제한은 동일합니다.

액세스 모드는 현재 세션이 입력 대기 상태일 때 하나씩 적용합니다.
Claude는 기본/편집 자동 허용/자동 판단/Bypass/계획, Codex는
기본/읽기 전용/자동 검토/전체 접근을 표시합니다. 실행기 버전에 따라
지원이 다를 수 있으므로 적용 뒤 서버 보고값을 확인하세요.
Bypass/전체 접근은 도구 승인 확인을 생략할 수 있으며 개별 승인과 다릅니다.
선택은 현재 세션에만 적용되고 직접 변경하기 전까지 유지합니다.
새로고침·재연결·같은 세션 재개만으로 기본 모드에 자동 복귀하지 않으며
다른 새 세션에는 자동으로 승계하지 않습니다. macOS 권한은 바꾸지 않습니다.
재개 직후에는 실행기 준비가 끝난 뒤 변경하세요. 변경 결과가 미확인이면
자동 재전송하지 않고 전송을 잠그므로 ‘설정 새로 확인’으로 조회합니다.
요청값이 반영되지 않은 미확인 상태의 해제 UX는 추가 보완 대상입니다.
원격 전용 기기는 로컬 AI 설정 없이 서버에 연결합니다.

채팅·첨부
도구 작업 묶음을 펼치면 파일 변경 전/후, 요청과 결과를 볼 수 있습니다.
하위 에이전트의 시작 요청 처리와 실제 완료는 구분합니다.
입력창 가까이의 확인 요청에서 허용·거절하거나 질문에 답변합니다.
표시된 세션 허용 범위 외의 권한은 부여하지 않습니다.
＋로 파일을 고르거나 입력창에 이미지/파일을 붙여넣고 끌어놓을 수 있습니다.
Mac 앱에서는 Finder 파일 복사와 미리보기의 이미지 복사 후 붙여넣기를 확인했습니다.
원격 웹의 붙여넣기는 브라우저가 실제 파일 데이터를 전달하는 경우에 지원합니다.
같은 이름의 파일도 개별 첨부이며 제거 버튼의 순서로 구분할 수 있습니다.
파일당 5MB, 합계 10MB, 최대 5개입니다. 보내기를 누를 때 서버에 업로드합니다.
첨부 초안은 세션별로 현재 창에서만 유지되며 새로고침/창 종료 후 사라집니다.
업로드 결과 미확인 시 자동으로 다시 보내지 않습니다.

3. 앱 작업 화면과 원격 접속
작업 화면은 Mac 앱 안에서 열립니다. 로컬은 일회용 연결로 자동 인증합니다.
왼쪽 하단 호스트 아이콘 → ‘컴퓨터 연결 관리’에서 서버를 등록하고 작업 화면을 엽니다.
이 항목은 이 Mac의 원격 역할이 켜져 있을 때 보입니다. 역할 변경은 같은 메뉴의 ‘이 Mac의 역할·설정’에서 합니다.
컴퓨터 전환은 왼쪽 하단 호스트 메뉴에서 합니다. 현재 컴퓨터 이름은 제목줄 오른쪽에 표시됩니다.
연결 관리와 설정은 같은 창에서 열고 제목줄의 뒤로가기로 이전 화면에 돌아옵니다.
돌아올 때 대화와 미전송 입력을 유지합니다.
창 제목줄의 왼쪽/오른쪽 아이콘으로 프로젝트 목록과 상세 패널을 각각 접고 펼칩니다.
왼쪽 목록을 접으면 호스트 아이콘도 숨겨지며, 제목줄의 왼쪽 아이콘으로 다시 표시합니다.
중앙 상단에는 세션 제목과 메뉴만 작게 표시합니다. 실행 상태는 입력창 근처에,
전송 대상은 입력창 아래에 표시합니다. 이력 통계는 세션 정보에서 확인합니다.
중앙에는 대화와 입력창이 계속 보이고, 파일·세션 정보는 오른쪽 패널의 탭에서 전환합니다. 도구 실행 상세는 대화 안의 접히는 도구 활동에서 봅니다.
패널을 닫았다 다시 열면 마지막 탭을 복원합니다. 파일은 가운데 탭으로 열리며, 파일 새로고침은 목록을 다시 읽습니다. 좁은 화면에서는 패널 닫기로 대화에 돌아옵니다.
컴퓨터 전환은 해당 서버의 작업을 종료하지 않습니다.
원격은 서버가 켜져 있고 같은 LAN·사내망 또는 Tailscale에 연결되어야 합니다.
서버 역할에서는 호스트 메뉴에 ‘서버 주소 설정’, ‘원격 접속 주소·토큰’, HTTPS 전달 항목이 나타납니다.
로컬 전용에서는 토큰 공유·원격 접속 정보가 표시되지 않습니다. 원격 컴퓨터를 선택하면 이 Mac의 서버 공유 항목도 숨깁니다.
토큰은 비밀번호처럼 취급하고 공개 URL·채팅·저장소에 넣지 마세요.
서버마다 토큰이 다르며 만료되면 재로그인이 필요합니다.
원격 브라우저의 ‘앱 설치 안내’에 따라 선택적으로 PWA를 설치할 수 있습니다.
서버가 꺼지면 작업을 실행하거나 오프라인으로 대신 처리할 수 없습니다.
QR 연결은 아직 제공하지 않습니다.

4. 접근 권한과 오류
공식 로그인을 눌렀는데 터미널 창이 나타나지 않는 경우:
- 먼저 Dock의 터미널에 로그인 창이 열려 있는지 확인합니다.
- 창이 없다면 Finder의 ‘이동 → 폴더로 이동’에서
  ~/Library/Application Support/MARICODE/local-setup/login/ 을 엽니다.
- 선택한 AI의 codex.login 또는 claude.login 폴더에 있는 기존
  login.command를 더블클릭합니다. 앱이 준비한 동일한 로그인 절차입니다.
- 완료 후 앱에서 ‘로그인 상태 확인’을 누릅니다. 실제로 Codex 자동 창 열기가
  시작되지 않은 사례에서 이 방법으로 로그인한 뒤 대화·재개를 확인했습니다.
- started/state.json이나 계정 파일을 삭제해서 재시도하지 마세요. 이미 실행을
  시작했거나 오류가 난 경우에는 터미널의 오류를 확인합니다. 인증 코드·토큰은
  채팅이나 공개 이슈에 올리지 마세요.

‘파일·폴더 접근 안내’에서 macOS 권한 설정 위치를 확인합니다.
원격 작업의 파일 권한은 파일이 있는 서버 Mac에서 허용해야 합니다.
macOS 권한·AI 도구 승인·서버 허용 경로는 서로 별개입니다.
승인 요청은 대화 입력창 위에 표시됩니다. 명령·경로를 확인하고 필요하면 ‘요청 상세’를 펼치세요.
‘이번만 허용’과 지원되는 요청의 ‘세션 허용’을 구분합니다. Claude의 같은 Bash 명령은
정확히 같은 명령에만 적용하고, Read/Glob/Grep 세션 허용은 해당 도구 전체 범위입니다.
Codex의 권한 요청은 ‘이번 응답 동안’ 또는 표시된 권한의 세션 허용을 제공합니다.
지원 범위를 확인할 수 없는 도구에는 세션 선택이 없습니다. 실행을 종료·재개하면 다시 승인이 필요할 수 있습니다.
폴더가 없어지거나 접근할 수 없으면 그 작업공간에 ‘폴더 확인 필요’를 표시합니다. 다른 프로젝트는 계속 사용할 수 있습니다.
종료된 대화는 메시지를 보내거나 설정을 적용할 때 해당 프로젝트·AI의 실행 환경을 준비해 같은 세션을 자동으로 다시 엽니다. 다시 열린 것이 확인된 뒤에만 메시지·설정을 보냅니다.
재개 결과가 불확실하면 자동 반복하지 않고 상태를 확인합니다. 파일 읽기만으로 AI를 재개하지는 않습니다.
파일 조회 때 실행 환경 연결 오류가 나면 파일 영역의 안내를 따라 컴퓨터 설정에서 실행 환경을 시작하고 다시 읽으세요.
전송 결과가 불확실하면 먼저 접수 상태를 확인하고 같은 요청을 다시 보내지 마세요.

5. 업데이트와 데이터
앱 메뉴의 ‘업데이트 확인…’에서 현재/공개 최신 버전과 변경사항을 확인합니다.
앱 시작 때도 공개 GitHub 안정 릴리스를 확인하며, 새 버전이 있으면 제목줄에 표시합니다.
일반 Git push나 원격 서버 업데이트가 아니라 이 Mac에 설치된 앱의 업데이트입니다.
‘다운로드’는 공개 DMG의 크기와 SHA-256을 확인한 뒤 ‘앱 종료 후 설치’를 제공합니다.
이 버튼은 앱의 정상 종료를 확인한 뒤 설치 디스크를 엽니다. 실행 중인 세션은 작업 화면에서 종료 여부를 확인합니다.
종료 취소·실패·미확인 상태에서는 설치를 진행하지 않습니다. 다시 시도하려면 업데이트 화면에서 직접 누르세요.
설치 디스크에서 Applications의 앱을 직접 교체합니다. 실행 파일을 자동 덮어쓰지 않습니다.
설치 디스크의 ‘처음 실행 안내.html’에서 해당 배포본의 설치 절차를 확인하세요.
공증 없는 배포본은 업데이트 후에도 ‘보안 설정 열기’를 통한 실행 승인이 필요할 수 있습니다.
설정을 자동으로 승인하지 않으며 ‘그래도 열기’는 사용자가 직접 선택합니다.

앱 닫기가 활성 세션 때문에 막히면 종료할 세션 목록과 ‘돌아가기’,
‘실행 종료 후 앱 닫기’를 표시합니다. 종료가 확인되면 앱 정상 종료를 이어갑니다.
답변 작성/승인 대기/미확인 요청은 먼저 정리해야 하며, 오류 때 강제 종료하지 않습니다.
대화·파일·설정은 보존하고 원격 서버의 실행은 종료하지 않습니다.
미전송 입력·첨부는 현재 창에만 있으므로 닫기 전에 보관하세요.

진행 중 작업·승인을 마무리하고 앱을 정상 종료한 뒤 새 앱으로 교체합니다.
앱 밖의 데이터 폴더를 삭제하지 마세요. 배포 빌드의 기본 위치는
~/Library/Application Support/MARICODE 입니다. 일반 업데이트에서는 유지하며,
이번1.1.0 전환의 첫 실행에만 위 안내대로 기존 데이터를 정리합니다.
개발 빌드는 기존 Merry Development 폴더를 사용합니다. 서로 자동 이관하지 않으며
배포 앱의 첫 실행에는 새 역할·AI 연결 설정이 필요합니다.
로컬 포트는 같으므로 개발 앱과 배포 앱을 동시에 시작하지 마세요.
인증 만료에 따른 재로그인은 대화 기록 삭제와 다릅니다.
지원하지 않는 데이터 형식 오류가 나면 마지막으로 사용한 버전으로 확인하고,
설정·DB·잠금 파일을 임의 삭제하지 마세요.

라이선스와 포함 소스는 ‘도움말 → 라이선스·소스 안내’에서 확인합니다.


왼쪽 목록 관리
- 각 행의 ⋯에서 프로젝트·작업공간·세션의 표시 이름을 변경합니다.
  실제 폴더 이름과 Git 브랜치는 바뀌지 않습니다.
- 프로젝트·추가 작업공간은 등록 해제, 종료된 세션은 목록에서 숨길 수 있습니다.
  실제 소스·Git 워크트리·대화 기록은 삭제하지 않습니다. 기본 작업공간은
  프로젝트와 함께 등록 해제합니다. 실행/승인 대기·미확인 작업이 있으면 차단합니다.
- 보기 설정 → 등록 해제·숨긴 항목 복원에서 같은 항목으로 되돌립니다.
  프로젝트를 복원한 뒤 그 안의 숨긴 세션을 복원할 수 있습니다.
- 미전송 입력이 있어도 +로 새 작업을 열 수 있습니다. 초안은 같은 창에서
  세션별로 유지하며 원래 대화로 돌아오면 복원됩니다. 로그아웃·창 종료 후
  초안은 유지되지 않습니다. 새 세션으로 자동 전송하지 않습니다.

프로젝트·작업공간·세션
- 프로젝트는 소스를 묶는 이름과 기준 폴더, 작업공간은 실제 작업할 폴더,
  세션은 그 작업공간에서 진행하는 AI 대화입니다.
- 대화 추가에서 새 대화/가져오기를 고르고 프로젝트·필요한 작업 폴더·AI를 선택합니다.
  기본 작업공간을 쓰면 별도 Git 설정 없이 대화로 진입합니다.
- 필요할 때 브랜치·워크트리 선택을 펼쳐 로컬 브랜치, 기존 워크트리,
  새 워크트리를 고릅니다. 새 워크트리에는 커밋된 내용만 들어갑니다.
- 기본 공간 하나면 프로젝트 행, 여러 공간이면 각 작업공간 행의 +로 대화를 추가합니다.
  +는 같은 폴더에 AI 세션을 추가합니다. 여러 세션의 파일은
  공유됩니다. 파일 변경을 분리하려면 새 워크트리 작업공간을 사용하세요.
- 실행 종료는 대화·작업공간·브랜치 삭제가 아닙니다.
- 보기 설정은 프로젝트별/작업공간별 목록과 세션 정렬·밀도 등을 바꿉니다.
- 활성 세션이나 미확인 생성이 있으면 브랜치 전환이나 새 폴더를 위한
  실행기 갱신이 제한될 수 있습니다. 작업 결과를 확인한 뒤 명시적으로 진행하세요.
- 여러 Git을 포함한 상위 폴더의 워크트리를 한 번에 복제하지 않습니다.

프로젝트 목록의 기본 작업공간 표시
기본 작업공간 하나뿐인 프로젝트는 프로젝트 바로 아래에 세션을 표시합니다.
작업공간/워크트리를 추가하면 각 작업공간 아래에 세션을 구분해 표시합니다.
검색 결과가 하나라고 계층을 합치지 않습니다. 실제 폴더·세션·작업공간 정보는 그대로 유지합니다.

기존 Claude Code 대화 가져오기 (1.0.3부터 지원, 폴더 선택·자동 탐색은 1.0.5부터)
1. 로컬 앱에서 원래 Claude를 실행한 폴더를 프로젝트/작업공간으로 등록합니다.
   여러 저장소를 품은 상위 폴더에서 Claude를 실행했다면 그 상위 폴더를 선택하세요.
   하위 저장소에서 실행했다면 해당 하위 폴더를 선택하세요.
2. ＋ → 기존 대화 가져오기 → 해당 프로젝트/작업 폴더를 선택합니다.
   Claude 또는 Codex를 선택합니다.
   새 세션 만들기와 별도 경로이며, 가져오기 화면에는 새 세션 생성 버튼이 없습니다.
3. 패널을 열면 선택한 작업 폴더의 기록을 자동으로 찾습니다.
   CLI의 CLAUDE_CONFIG_DIR 환경변수, 셸 설정에 명시된 단일 경로를 확인하고
   별도 설정이 없으면 ~/.claude에서 찾습니다. 찾은 폴더와 출처를 화면에 표시합니다.
   별칭/함수/조건문/명령 치환이나 여러 후보는 실행·추측하지 않고 직접 선택을 안내합니다.
   ‘기록 위치·가져오기 안내’를 펼친 뒤 ‘기록 폴더 선택…’에서 projects가 들어 있는 Claude 설정 폴더를 고르세요.
   숨김 폴더도 보이며 선택하면 같은 작업 폴더의 기록을 자동으로 다시 찾습니다.
   프로젝트 소스 폴더나 projects 하위 폴더를 고르는 것이 아닙니다.
   ‘기록 저장 위치 직접 입력’에는 절대 경로나 ~/ 경로를 입력할 수도 있습니다.
   ‘검색 위치 확인’에서 실제 검색 폴더를 확인하세요. 계정·설정은 바꾸지 않습니다.
4. 저장된 사용자 지정/AI 제목(없으면 입력 일부)·날짜로 대화를 선택합니다.
   50개씩 표시하며 ‘이전 세션 더 보기’로 나머지를 불러옵니다. 큰 기록이나 문제가 있는
   기록도 사유와 함께 표시합니다. 가져오기 한도는 파일당256MiB·전체512MiB입니다.
   목록 옆 새로고침 아이콘으로 최신 목록을 조회하며 마지막 확인 시각을 표시합니다.
   원본 작업을 마친 뒤 선택한 세션 가져오기를 누릅니다. 별도 확인 체크박스는 없습니다.
5. 등록과 이전 기록 조회를 확인한 뒤 가져온 대화를 엽니다. 실패하면 가져오기 화면에서
   오류를 표시합니다. 등록 후 화면 열기만 실패한 경우 가져온 대화 다시 열기를 사용합니다.
   같은 ID를 열며 복사·등록을 반복하거나 새 세션으로 대신하지 않습니다.
   가져온 이전 대화가 자동으로 펼쳐지고 최근 내용부터 표시됩니다.
   이전 기록과 새 대화는 같은 영역에서 스크롤하며 더 오래된 기록은
   ‘가져온 기록 더 보기’로 조회합니다. 연결 준비 후 자동으로 같은 세션을 재개하며,
   실패하면 원인을 확인한 뒤 수동으로 재개합니다.
   화면의 기록 표시와 AI가 실제로 이전 맥락을 이어받는 것은 별개입니다.
   실제 응답에는 Maricode에 연결한 Claude 계정의 공식 로그인이 필요합니다.

원본 대화와 파일은 변경하지 않습니다. 선택한 JSONL과 해당 subagents JSONL만
전용 프로필로 복사하고 원래 native ID를 재개합니다. 이후 양쪽 대화는 자동 동기화되지
않습니다. 계정·MCP·설정·메모리·첨부 파일은 복사하지 않으므로 필요한 환경은 따로
준비하세요. 가져오기만으로 브랜치를 바꾸거나 worktree를 만들지 않습니다.
이전 기록은 읽기 전용 텍스트 50개씩 표시하며 긴 메시지는 화면에서만 일부 생략합니다.
과거 도구·첨부 이벤트는 요약하고 승인/도구 실행을 다시 보내지 않습니다.
같은 ID의 기존 대상 파일은 덮어쓰지 않습니다. 응답 유실 시 가져오기 결과 확인은
조회만 합니다. 원본이 바뀌었거나 형식을 확인할 수 없으면 가져오기를 중단합니다.
목록은 최신순50개씩 추가 조회합니다. 이전의500개 후보/누적128MiB 검색 제한은
없앴습니다. 가져오기는 파일당256MiB·본체와 하위 기록 합계512MiB까지 확인합니다.
목록에 없는 경우 원래 실행 폴더·설정 폴더·파일 접근 권한을 확인하세요.
같은 Claude 세션이 다른 기기 경로에서 이어진 행도 보존합니다. 다른 프로젝트나
세션의 기록을 섞거나 원본 경로를 바꾸지는 않습니다. 원격 화면에는 가져오기를 노출하지 않습니다.

새 세션 기본값과 일반 대화 (1.0.4부터)
- 같은 작업공간의 최근 세션에서 AI·모델·추론 값을 가져옵니다. AI는 생성 전에
  바꿀 수 있습니다. 모델·추론은 새 세션에서 지원 여부를 조회한 뒤 적용하며
  지원하지 않거나 조회하지 못한 값은 적용하지 않았다고 표시합니다.
  계정·승인·액세스 수준은 자동 복사하지 않습니다.
- 프로젝트 없이 시작하려면 빈 화면의 ‘프로젝트 없이 일반 대화’ 또는
  새 작업 → 일반 대화 → AI 선택 → 대화 시작을 사용하세요.
  실행용 폴더는 앱이 관리하며 기존 소스 폴더·홈 폴더를 대신 선택하지 않습니다.
  목록의 ‘일반 대화’에서 기존 대화를 이어갈 수 있습니다. 일반 대화도 AI 계정
  연결은 필요합니다. 도구 접근은 기존 AI 권한을 따르며 MCP를 자동 설정하지 않습니다.

대화 준비 화면의 AI 연결 상태
연결됨이면 별도의 로그인 확인이나 실행 파일 연결을 할 필요가 없습니다.
연결 문제나 미로그인일 때만 해결 버튼이 나타납니다. 상세 계정 관리는
오른쪽 세션 정보의 ‘실행 머신의 AI 계정’을 펼쳐 확인합니다.

Claude 가져오기 검증 안내 (1.0.9)
프로젝트에서 시작해 하위 폴더에서 이어간 같은 세션도 가져올 수 있습니다.
프로젝트 밖의 기록·다른 세션 ID·지원하지 않는 형식은 자동으로 섞지 않습니다.
오류가 나면 표시된 행 번호와 원인 코드만 알려 주세요. 회사 경로·대화 본문은
보낼 필요가 없습니다. 가져오기를 위해 원본 기록을 수정하거나 지우지 마세요.

1.0.12 추가 기능
- Codex 가져오기: 프로젝트 및 그 하위 폴더에서 시작한 기존 대화를 찾습니다.
  기본 ~/.codex 또는 직접 지정한 기록 폴더의 선택한 rollout만 전용 프로필로
  복사합니다. 프로젝트 폴더에서 같은 스레드를 자동 재개하고 이전 대화를 표시합니다.
  인증·설정·MCP·상태 DB는 복사하지 않습니다. 하위 폴더 시작 기록은 목록 검사만
  자동 검증했으며 실제 재개는 아직 확인하지 않았습니다.
- AI 계정: 별칭을 붙여 계정을 추가·전환·이름 변경·목록 삭제할 수 있습니다.
  한 AI는 한 번에 한 계정만 사용합니다. 실행 중 대화나 미확인 요청이 있으면
  전환할 수 없습니다. 대화는 원래 기록이 있는 계정에서만 재개합니다.
  목록 삭제는 로그인 폴더 삭제가 아니며 기본/사용 중 계정은 삭제하지 않습니다.
- 모델 설정: Claude 계정 모델 목록과 지원 추론 수준, Codex가 지원하는 Fast와
  계획 먼저 옵션을 표시합니다. Fast는 사용량을 더 쓸 수 있으며 자동으로 켜지 않습니다.
- 컨텍스트 사용량은 엔진 보고값이 있을 때 표시합니다. 구독 잔여량은 제공하지 않습니다.
  입력창의 /에는 엔진 목록 중 Maricode 실행 경로가 확인된 명령만 표시합니다.
  미지원 명령을 직접 입력하면 전송하지 않고 입력을 보존해 안내합니다. 명령 카드는
  아래 범위를 제공하며 설치된 CLI의 지원 여부를 확인합니다. $는 엔진이 제공하는 스킬 목록입니다.
- 다른 AI 인계: 세션 정보에서 같은 프로젝트의 다른 AI 대화를 만들고 최근 텍스트
  일부를 초안으로 넣습니다. 전달 범위를 확인한 뒤 직접 전송합니다.
- Codex의 지원 대화에서는 내 메시지의 ‘여기서 분기’로 직전 대화를 복제합니다.
  원래 대화와 파일은 되돌리지 않습니다. Claude 특정 메시지 분기는 미지원입니다.
- 오른쪽 세션 정보에서 Git 변경 내용을 읽기 전용으로 검토할 수 있습니다.
- 오른쪽 파일 탭에서 파일을 누르면 가운데 ‘대화’ 옆에 읽기 전용 파일 탭이 열립니다. 코드는 색 구분,
  마크다운은 보기 모드(‘원본’으로 전환), 이미지·영상·오디오·PDF는 바로 표시합니다. 8MB가 넘는
  텍스트는 열지 않습니다.
- 명령 팔레트(⌘K/Ctrl+K)와 대화 내 찾기(⌘F), 다른 대화의 작업 완료 알림을
  제공합니다. 단축키는 헤드리스 Chrome에서 검증했고 네이티브 메뉴와의 동작은 미확인입니다.
- 서버 Mac의 로그인된 로컬 화면에서 ‘다른 기기 연결 코드’로 8자리 코드를 만듭니다.
  원격 로그인 입력칸에 코드를 넣습니다. 5분·1회용이고 연속 5회 실패 시 폐기됩니다.
  같은 LAN/Tailscale 접근과 서버 실행이 필요하며 QR 이미지는 아직 제공하지 않습니다.

채팅 명령 카드 (1.0.12)
- 실행 컴퓨터의 로컬 앱/loopback 화면에서 세션을 선택하고 /를 입력하세요.
  설치된 CLI가 지원하고 해당 세션의 계정·폴더를 확인한 카드만 제안합니다.
- Claude/Codex 공통: /mcp는 등록 서버 목록, /plugins는 설치 플러그인 목록,
  /account는 현재 AI 로그인 상태를 표시합니다. Codex /doctor는 진단 항목별
  정상·확인 필요·실패를 표시하며 자동 복구하지 않습니다.
- /mcp → ‘MCP 설정 변경’에서 HTTP 서버 이름·주소를 입력하고 추가를 검토합니다.
  목록의 ‘삭제 검토’로 기존 서버를 제거할 수 있습니다. Claude는 local/project/user
  범위를 명시하고 Codex는 현재 계정 프로필을 사용합니다. 같은 설정을 쓰는 다른
  세션에도 영향을 줄 수 있으므로 대상과 범위를 확인한 뒤 ‘변경 확인’을 누르세요.
- 인증정보·쿼리가 포함된 주소는 받지 않습니다. OAuth·stdio 서버·직접 수정·
  플러그인 설치/삭제는 아직 카드 미지원입니다. 필요한 인증은 공식 CLI를 이용하세요.
  Codex 추가 과정에서 CLI가 인증을 요구하면 변경 결과가 미확인으로 남을 수 있습니다.
- 저장 후 ‘적용하고 이어가기’는 실행 종료 확인을 거쳐 같은 세션을 재개합니다.
  대화·작성 중 입력은 보존하고 작업 중/승인 대기/미확인 상태는 자동 재시작하지 않습니다.
  설정 저장·CLI 조회와 실제 AI 세션의 MCP 연결/도구 사용 성공은 서로 다릅니다.
- 응답 유실은 ‘결과 확인’으로 조회하세요. 변경을 다시 보내지 않습니다. 미확인 변경은
  후속 변경·계정 전환을 막으며 자동으로 잠금을 해제하지 않습니다. 결과 카드 내용은
  AI에게 보내거나 대화 이력에 저장하지 않습니다. 재로딩 후 같은 명령 카드를 열면
  미확인 요청 ID를 다시 조회할 수 있습니다. 암호나 토큰은 카드에 넣지 마세요.

공식 CLI와 MCP 설정 (고급 보조 기능)
- AI 계정 화면에서 Claude의 ‘공식 CLI · MCP 설정’ 또는 Codex의 ‘공식 CLI 열기’를
  펼치고 작업 폴더를 고른 뒤 ‘공식 CLI 열기’를 누릅니다. 해당 Mac의 로컬 화면에서만
  사용할 수 있으며 현재 계정과 등록된 실행 파일을 사용합니다.
- 별도 터미널에서 공식 CLI가 열립니다. 기존 앱 대화를 재개하지 않고 터미널의 대화는
  앱에 자동 표시되지 않습니다. 기존 대화 이어가기는 앱의 실행 재개를 이용하세요.
- Claude 안에서는 /mcp로 관리합니다. CLI를 마친 뒤 같은 터미널에서
  claude mcp --help로 추가·삭제·인증 등 설치된 버전의 명령을 확인할 수 있습니다.
  선택한 프로필을 유지하려고 개인 셸 초기화 파일은 불러오지 않습니다.
- 설정 변경은 같은 계정·프로젝트의 다른 세션에도 영향을 줄 수 있습니다. 기존 앱
  실행에 즉시 적용됐다고 간주하지 말고 필요하면 실행 종료 후 재개하세요.
  암호·인증 코드는 터미널이나 공식 화면에만 입력하세요.
- 끝나면 CLI를 종료하고 exit로 셸도 닫은 뒤 앱의 ‘상태 확인’을 누릅니다.
  열기 결과가 미확인이면 자동 재실행하지 않습니다. 앱을 닫아도 별도 터미널은 남습니다.

모델·액세스 설정 보완 (1.0.13)
- 모델 선택 별칭과 실제 실행 기록의 전체 모델 ID를 구분합니다. 보고된 ID가 없으면 버전 미확인으로 표시하며 최신 버전을 임의로 추정하지 않습니다.
- 종료된 세션에서도 액세스 모드 목록을 살펴볼 수 있습니다. ‘세션 재개 후 설정하기’로 재개한 다음 선택을 확인하고 적용하세요. 선택이나 재개만으로 권한을 확대하지 않습니다.
- 작업 중·승인 대기·미확인 요청이 있으면 설정 적용을 제한하고 이유를 표시합니다.

CLI 연결 전환 안내 (다음 배포 적용)
이번 전환 업데이트에서만 기존 Maricode 전용 AI 프로필을 한 번 정리하고 연결을 다시 받습니다.
전용 프로필에만 있던 시험 세션은 재개할 수 없습니다. 터미널의 .claude-global/.claude/.codex와
프로젝트 파일은 삭제하지 않습니다. 완료 표식 이후에는 같은 정리를 반복하지 않습니다.

공식 CLI 직접 실행과 앱 채팅은 경로가 다릅니다.
- 공식 CLI 보조 창: 연결한 CLI와 설정 위치에서 별도 터미널을 엽니다.
- 채팅 내 명령 카드: 같은 CLI의 지원 명령을 호출해 목록·설정·인증 결과를 표시합니다.
- 앱 대화: HAPI를 거쳐 공식 CLI를 실행합니다. 같은 설정 위치를 쓰지만 HAPI가
  추가하는 지시문·권한 옵션·MCP bridge가 있으므로 터미널과 완전히 같지는 않습니다.
명령 카드의 MCP 목록은 실행 중 대화의 연결 상태를 보장하지 않습니다.
설정 변경 후에는 ‘적용하고 이어가기’로 정상 종료·재개하고 실제 도구 연결을 확인하세요.
셸 함수·별칭·추가 환경변수는 자동으로 실행/복사하지 않습니다.
같은 설정 폴더의 기존 세션은 복사 없이 연결합니다. CLI와 앱에서 같은 대화를 동시에 실행하지 마세요.
CLI 기본 위치는 자동 찾기를 사용하세요. 기본 연결은 프로필 환경변수를 덮어쓰지 않습니다.
Claude 기본 실행은 홈의 .claude.json을 읽지만 CLAUDE_CONFIG_DIR을 지정하면
지정 폴더 안의 .claude.json을 읽으므로, 단순히 같은 폴더 경로를 넣는 것과 다를 수 있습니다.
