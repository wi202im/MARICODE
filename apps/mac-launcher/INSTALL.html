Apple Silicon Mac용 · 이 배포본은 Apple 공증을 받지 않았습니다.

1. 응용 프로그램으로 복사

디스크 이미지의 MARICODE를 Applications 폴더로 끌어놓으세요. 이전 앱이 실행 중이면 먼저 작업과 앱을 정상 종료합니다.

2. 복사한 앱 실행

응용 프로그램 폴더에서 MARICODE를 실행하세요. ‘Apple이 악성 코드가 없음을 확인할 수 없습니다’라는 창이 나타나면 완료를 누릅니다.

3. 이 앱의 실행 허용

  1. 아래 버튼으로 개인정보 보호 및 보안을 엽니다.
  2. 아래쪽 보안 영역에서 MARICODE 옆 그래도 열기를 선택합니다.
  3. Mac 인증 후 열기를 눌러 완료합니다.

버튼이 동작하지 않으면 시스템 설정 → 개인정보 보호 및 보안으로 이동하세요. ‘그래도 열기’가 없다면 응용 프로그램 폴더에서 앱 실행을 한 번 시도한 후 다시 확인하세요.

업데이트할 때

앱에서 다운로드 후 앱 종료 후 설치를 누르세요. 정상 종료를 확인하면 설치 디스크가 열립니다. 실행 중인 세션은 작업 화면에서 종료 여부를 확인합니다. 취소하거나 종료를 확인하지 못하면 설치하지 않습니다. 설치 디스크에서 앱을 Applications로 옮겨 교체하세요. 계정·설정·대화가 저장된 Application Support 폴더는 삭제하지 않습니다. 미전송 입력과 첨부는 종료 전에 보관하세요. 공증이 없는 배포본이므로 업데이트 뒤에도 위의 그래도 열기 확인이 필요할 수 있습니다.

Apple의 앱 실행 안내 · 공식 배포 페이지

전체 보안을 끄거나 격리 정보를 삭제할 필요는 없습니다. ‘컴퓨터를 손상시킵니다’ 또는 ‘손상된 앱’처럼 다른 경고가 표시되면 실행을 중단하고 공식 배포 파일을 확인하세요.
