1.2.6 업데이트

1.1.0의 전체 초기화를 실행하지 않습니다. 기존 설정·프로젝트·대화를 유지합니다. 진행 중인 작업과 앱을 정상 종료한 뒤 교체하세요.

1. 앱 복사

디스크 이미지의 Maricode를 Applications로 끌어놓으세요. 기존 앱이 실행 중이면 작업과 앱을 정상 종료한 뒤 교체합니다.

2. 앱 실행

디스크 이미지를 추출하고 응용 프로그램 폴더에서 Maricode를 여세요. 인터넷에서 다운로드한 앱인지 확인하는 macOS 창이 나타나면 앱 이름과 출처를 확인하세요.

기존 버전의 ‘그래도 열기’ 절차는 이 공증본의 기본 설치 과정이 아닙니다. ‘손상된 앱’이나 악성 코드 경고가 나타나면 보안을 끄지 말고 공식 배포 파일을 확인하세요.

업데이트와 데이터

계정·설정·대화는 앱 바깥의 Application Support에 보관됩니다. 이 폴더를 삭제하지 마세요. 미전송 입력과 첨부는 종료 전에 보관하세요.

Claude·Codex 설치 및 공식 계정 로그인, 작업 폴더 접근 권한은 별도입니다. 앱 공증이 파일 접근 권한을 대신하지 않습니다.
